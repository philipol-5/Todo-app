# Todo App

A clean and modern JavaScript todo app with inline validation and task controls.

## Features

- Add new tasks with a styled input form
- Validation feedback for empty submissions
- Mark tasks as done
- Remove tasks from the list
- Keyboard-friendly form submission

## Project Structure

- `index.html` — app layout and structure
- `index.css` — modern UI styling and responsive layout
- `script.js` — form handling, validation, and task management

## Getting Started

### Option 1: Open locally

1. Clone or download the repository.
2. Open `index.html` in your browser.

### Option 2: Run with a local server

If you prefer a local server, use a tool like VS Code Live Server or a simple HTTP server:

```bash
# Python 3
python -m http.server 8000
```

Then open:

```
http://localhost:8000
```

## Usage

1. Type a task into the input field.
2. Press `Add` or hit `Enter`.
3. Click `Done` to mark a task complete.
4. Click `Remove` to delete a task.

## Notes

- This app uses plain HTML, CSS, and JavaScript.
- No external dependencies are required.
- You can extend it by adding persistence with `localStorage` or improving accessibility.
